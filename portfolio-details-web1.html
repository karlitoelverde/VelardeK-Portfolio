Copartner Chatbot Assistant using Flutter Web and Supabase

Copartner Chatbot Assistant is created to lessen the workload of IT personnel by efficiently addressing the issues and concerns of police personnel across the country in different regions. The system uses a rule-based chatbot to provide accurate, context-aware responses, and integrates several modules for streamlined administration and support.

The web admin dashboard, built with Flutter and powered by Supabase and Netlify, enables real-time management of users, documents, support tickets, and more. Concerns are resolved quickly, either through automated chatbot responses or direct communication with IT admins.

Key Features

  • Dashboard Module:
    • Displays calendar, current time, and a history of emails sent from the mobile chatbot app to the Flutter web admin.
  • Users Module:
    • Shows all users with access to the Copartner mobile app, including rejected, pending, and users requesting password changes.
  • Issues and Concerns Module:
    • Main purpose of the app: the chatbot assistant answers user issues and concerns using a rule-based format, analyzing tokens and word percentages to provide the most relevant response based on admin input.
  • Document Management Module:
    • Admins can upload, edit, and delete multiple documents and PDFs. Changes are reflected in the mobile app, where users can read or download files using a PDF viewer or similar tool.
  • Support Ticket Management:
    • If the chatbot cannot resolve a user's concern, the user can submit a support ticket via the mobile app. Admins can respond directly, and both parties can chat and exchange images for more accurate issue resolution.
